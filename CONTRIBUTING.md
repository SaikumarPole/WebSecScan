# Contributing to WebSecScan

We welcome contributions to WebSecScan! To contribute, please follow these guidelines:

## PR Workflow

1. Fork the repository: `git fork https://github.com/your-username/WebSecScan.git`
2. Make changes: modify the code to fix a bug or add a new feature
3. Submit a pull request: `git pull-request https://github.com/your-username/WebSecScan.git`

## Commit Standards

* Follow the GitHub commit guidelines: https://github.com/commit-guidelines

## Code Style Rules

* Follow PEP 8: https://www.python.org/dev/peps/pep-0008/
